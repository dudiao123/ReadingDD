# 阅读DD

基于 [Legado](https://github.com/gedoor/legado) 与 [Legado with MD3](https://github.com/HapeLee/legado-with-MD3) 修改的 Android 阅读应用。

阅读DD 由个人开发维护，专注于把小说、漫画和动漫内容集中到一个简洁易用的阅读工具中。

## 主要功能

- 小说、漫画、动漫三个独立板块
- 书源导入自动识别类型，并支持直接检测和调试
- 无效书源、需要登录的书源自动标记，便于清理
- 不同板块使用独立的搜索、发现和分组
- 漫画阅读优化，支持缓存、预加载和双页阅读
- 动漫播放优化，支持 HLS、播放进度、倍速和自动下一集
- Material 3 界面，支持本地备份与恢复
